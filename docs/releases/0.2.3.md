# MySSH 0.2.3

Stability and responsiveness fixes from a full code review.

## Fixed
- Closing a terminal or SFTP tab while it was still connecting left the SSH connection (and every jump host) open until MySSH quit.
- Long AI answers no longer slow the app down while they stream: the text is updated in small batches and only the part that changed is redrawn. Text you select in an earlier paragraph stays selected.
- Starting a new chat, opening another conversation or asking about terminal text now stops a chat that is still running (it used to keep calling the model and running tools in the background). A stalled Claude stream now ends with a network error after 3 minutes.
- Database, keychain, private-key decryption and the AI agent loop no longer run on the UI thread, so the window stays responsive (also while macOS asks for keychain access).
- SFTP: a dropped connection or timeout shows an error in the tab instead of an "unexpected error"; idle SFTP tabs are kept alive; very large folders and uploading many files at once are much faster.
- Terminal: ending a session after a flood of output no longer freezes the window, and holding Cmd/Ctrl over very long wrapped lines is fast again.
- The Settings page no longer leaks memory each time it is opened.
- If MySSH cannot open its data when started from the tray, it now shows the window with the error instead of staying hidden.

## Install
- **macOS** (Apple silicon): `MySSH-osx-Portable.zip` — unzip and move MySSH.app to Applications. Signed and notarized.
- **Windows** (x64): `MySSH-win-Setup.exe` or `MySSH-win-Portable.zip`. Not code-signed yet: if SmartScreen appears, choose **More info → Run anyway**.

Installed apps update themselves (Settings → Updates).
