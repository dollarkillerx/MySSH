# MySSH 0.2.2

## Fixed
- **Windows**: the caption bar showed a fourth, full-screen button that overlapped the language button, and full screen hid the minimize / maximize / close buttons. MySSH now shows only minimize, maximize and close, like other Windows apps.
- **Linux** (built from source): the window keeps the window manager's title bar instead of a drawn one that ignored the window shadow and border.

## Install
- **macOS** (Apple silicon): `MySSH-osx-Portable.zip` — unzip and move MySSH.app to Applications. Signed and notarized.
- **Windows** (x64): `MySSH-win-Setup.exe` or `MySSH-win-Portable.zip`. Not code-signed yet: if SmartScreen appears, choose **More info → Run anyway**.

Installed apps update themselves (Settings → Updates).
