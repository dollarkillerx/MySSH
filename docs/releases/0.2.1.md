# MySSH 0.2.1

## Fixed
- **Windows**: the minimize, maximize and close buttons were invisible in the light theme (dark glyphs on the dark header). They are now drawn in the Carbon header style, with a red close button on hover.

## Install
- **macOS** (Apple silicon): `MySSH-osx-Portable.zip` — unzip and move MySSH.app to Applications. Signed and notarized.
- **Windows** (x64): `MySSH-win-Setup.exe` or `MySSH-win-Portable.zip`. Not code-signed yet: if SmartScreen appears, choose **More info → Run anyway**.

Installed 0.2.0 apps update themselves (Settings → Updates).
