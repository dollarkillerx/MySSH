# MySSH 0.2.5

## New
- **繁體中文** and **한국어**: MySSH is now available in Traditional Chinese and Korean (Settings → Language, or the language menu in the top bar). It follows your system language: Traditional Chinese for zh-Hant / Taiwan / Hong Kong / Macau, Korean for Korean systems.
- Each script uses its own fonts (PingFang TC / Microsoft JhengHei for Traditional Chinese, Apple SD Gothic Neo / Malgun Gothic for Korean), so characters keep their regional shapes and never mix fonts in one line.
- The website is available in both languages too: https://myssh.pages.dev/zh-tw/ and https://myssh.pages.dev/ko/

## Install
- **macOS** (Apple silicon): `MySSH-osx-Portable.zip` — unzip and move MySSH.app to Applications. Signed and notarized.
- **Windows** (x64): `MySSH-win-Setup.exe` or `MySSH-win-Portable.zip`. Not code-signed yet: if SmartScreen appears, choose **More info → Run anyway**.

Installed apps update themselves (Settings → Updates).
