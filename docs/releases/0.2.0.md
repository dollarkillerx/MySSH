# MySSH 0.2.0

The first release of the rewritten MySSH (.NET 10 + Avalonia, IBM Carbon design). Releases up to v0.0.4 were the previous Tauri version.

This release is for **macOS on Apple silicon**. Windows and Linux can be built from source for now.

## What's new
- Native terminal with IME support, search and clickable links; SSH with jump hosts and proxies; SFTP browser and editor.
- Hosts, identities and known hosts, encrypted on disk with the key in the macOS Keychain (or behind a master password).
- MCP server: Claude Code, Claude Desktop and other MCP clients can list hosts, run commands and use SFTP, under per-host policies with approvals and an audit log.
- Built-in AI assistant (Claude, OpenAI, DeepSeek or an OpenAI-compatible server such as Ollama) that can read the terminal and suggest commands; actions follow each host's AI policy.
- Automatic updates (Settings → Updates).

## Install
Download `MySSH-osx-Portable.zip`, unzip it and move **MySSH.app** to Applications. On first start MySSH offers to import hosts from the Tauri version.
