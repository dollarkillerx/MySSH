# MySSH 0.2.4

## Fixed
- The AI assistant panel now stays on the newest message: it follows a streaming answer as it grows, and opening a conversation shows its latest messages. Scroll up to read earlier messages and it stays where you are until you ask again.

## Install
- **macOS** (Apple silicon): `MySSH-osx-Portable.zip` — unzip and move MySSH.app to Applications. Signed and notarized.
- **Windows** (x64): `MySSH-win-Setup.exe` or `MySSH-win-Portable.zip`. Not code-signed yet: if SmartScreen appears, choose **More info → Run anyway**.

Installed apps update themselves (Settings → Updates).
